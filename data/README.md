# EduPulse AI — Data Architecture & Storage Layers

This directory organizes the raw registrar inputs and processed feature matrices for the EduPulse AI classroom analytics platform.

---

## 🏛️ Directory Structure

```
data/
├── raw/                          # Raw tabular institutional data
│   ├── assessments.csv           # Student marks across semester assessments
│   ├── attendance.csv            # Individual session attendance records (Present/Late/Absent)
│   ├── ground_truth_labels.csv   # Evaluation labels (archetype assignment for benchmarking)
│   ├── lms_activity.csv          # Coursework submission records & delay metrics
│   └── students.csv              # Student directory and demographic attributes
├── processed/                    # Feature matrices and scored batch outputs
│   ├── features.csv              # 12-feature matrix generated by feature_engineering.py
│   └── risk_scores.csv           # Batch inference risk scores, labels, and SHAP factors
└── README.md                     # Data documentation
```

---

## 📋 Input Schemas & Required Columns

### 1. `students.csv`
- `student_id` (string, required): Unique student identifier (e.g., `STU1001`).
- `name` (string, required): Full student name.
- `email` (string, required): University email address.
- `class_id` (string): Cohort / section code (default: `CS101`).
- `department` (string): Academic department (default: `Computer Science`).

### 2. `attendance.csv`
- `student_id` (string, required): Foreign key matching `students.csv`.
- `date` (string, YYYY-MM-DD): Session date.
- `status` (string, required): One of `Present`, `Late`, `Absent`.
- `course_id` (string): Course code.

### 3. `assessments.csv`
- `student_id` (string, required): Student identifier.
- `assessment_name` (string, required): e.g., `Quiz 1`, `Midterm Exam`.
- `date` (string, YYYY-MM-DD): Date of assessment.
- `max_score` (float, required): Total possible points (e.g., `100.0`).
- `score_obtained` (float, required): Points achieved by student.

### 4. `lms_activity.csv`
- `student_id` (string, required): Student identifier.
- `activity_type` (string, required): Assignment or module title.
- `delay_days` (float, required): Days submitted after deadline (0 for on-time).
- `completion_status` (string, required): `Completed`, `Late`, or `Missing`.
